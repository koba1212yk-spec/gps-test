許可ダイアログが出ない・許可したのに取れないとき
  1. ダイアログはボタンを押したときだけ出ます。ページを開いただけでは出ないのがブラウザの決まりです。まず「現在地を取得」を押してください。
  2. スマホ本体の位置情報がONか確認してください（設定 → 位置情報）。OFFだとダイアログすら出ずに失敗します。
  3. アプリの権限：設定 → アプリ → Muse → 権限 → 位置情報 が「許可（常に許可／アプリの使用中のみ許可）」になっていれば、この段はOKです。最終アクセスに時刻が残っていれば、スマホ → アプリの間は正常に動いている証拠なので、アプリの権限をいじっても直りません。原因は次の段（アプリ → このページ）です。
  4. それでもダイアログが出ず、押してすぐエラーになる場合は、このページ（サイト）側に「拒否」が残っているか、アプリ内ブラウザがページへ位置情報を渡せていません。上のチェックで「このページへの許可」が拒否されていますと出たらサイト側の拒否です。ページを開いている画面の設定（メニュー → サイト設定など）で、このページの位置情報を「許可」に戻してください。
  5. 上のチェックで許可済みと出ているのに取れない場合は、このページを一度閉じて開き直すと直ることがあります。
  6. チェックが「まだ決まっていません」のまま、ダイアログも一切出ない場合は、アプリ内ブラウザが確認画面そのものを出せていない可能性が高く、このページ側からは直せません。Museアプリの再起動と最新版への更新を試して、それでもダメなら同じページをChromeなどの通常ブラウザで開いてみてください（通常ブラウザでは確認画面が正常に出ます）。
